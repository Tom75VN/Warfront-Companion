# Warfront Companion

Releases of the Warfront Companion for WoW: Forever (Windows). This repository holds downloads only, no source code.

- Download the latest `Warfront-Companion-<version>-win-x64.zip` from [Releases](../../releases), together with its `.sha256` file.
- Check the SHA-256 of the zip, extract the folder, and run `Warfront.Companion.exe` once. It starts with Windows and lives in the notification area.
- The companion updates itself: it only installs an archive whose SHA-256 matches the one published by the Warfront cloud.
