# Warfront Companion

The companion app for the **Warfront** addon on **WoW: Forever**. It keeps your progress in sync with the Warfront cloud, so your characters, campaigns and leaderboards are up to date when you log in.

## Install

**Windows**
1. Download and open the `.msi` file.
2. If Windows SmartScreen warns you, click **More info**, then **Run anyway** (the app is not code-signed yet).
3. That's it: no administrator rights needed. The companion starts with Windows and lives in the notification area.

**Mac**
1. Download and open the `.dmg` file.
2. Drag **Warfront Companion** onto the **Applications** shortcut.
3. On first launch, macOS may block the app: open **System Settings > Privacy & Security** and click **Open Anyway**.

The companion updates itself afterwards. You never need to download it again.
